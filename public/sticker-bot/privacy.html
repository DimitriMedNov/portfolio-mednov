Política de privacidad de Sticker Bot Personal

Última actualización: 29 de julio de 2026.

Datos procesados

Sticker Bot Personal recibe las imágenes que el usuario envía voluntariamente por WhatsApp, su número telefónico y los identificadores técnicos necesarios para procesar el mensaje.

Uso de la información

La información se utiliza únicamente para convertir la imagen recibida en un sticker y devolverlo al usuario mediante WhatsApp.

Almacenamiento

Las imágenes se procesan temporalmente y no se almacenan de forma permanente en una base de datos.

Servicios externos

El servicio utiliza WhatsApp Cloud API de Meta para recibir y enviar mensajes y Cloudflare Tunnel para conectar temporalmente el webhook con el servidor local.

Eliminación de datos

Para solicitar la eliminación de cualquier registro técnico relacionado con el servicio, envía un correo a mednov@outlook.es con el asunto “Eliminación de datos de Sticker Bot Personal” e incluye el número de WhatsApp desde el que utilizaste el bot.

Contacto

Correo: mednov@outlook.es
